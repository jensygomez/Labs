[[Laboratorios del LFCS]]


---

In Linux, I learned that everything is organized around the root directory, which is the top-level directory represented by "/". The system uses a hierarchical structure of files and directories, similar to an inverted tree. This philosophy makes the operating system very organized and predictable. Understanding absolute and relative paths is essential because it allows me to move efficiently through the file system and locate any file or directory without confusion.

This lab helped me practice the basic but very important skills of file and directory management. I practiced creating directories and files, copying them with or without preserving attributes, moving content, deleting files and directories, and working with links. I also learned how to create multiple nested directories in one command using the `mkdir -p` option and how to view the full modification time of files. These operations represent the Linux way of giving the administrator full control with simple and powerful commands.

Mastering these fundamentals gives me confidence when working on any Linux system. Even though they seem basic, they are used every day by system administrators. In a technical interview, I can explain that I understand the Linux file system structure, how to manipulate files safely, and the difference between soft and hard links. This knowledge forms the foundation for more advanced topics and shows that I can work comfortably in the terminal.

---

**Key commands to remember:**

- `pwd`
- `cd ..`
- `mkdir -p`
- `cp -a` (preserve attributes)
- `ln -s` (soft link) / `ln` (hard link)
- `ls -l --full-time`
