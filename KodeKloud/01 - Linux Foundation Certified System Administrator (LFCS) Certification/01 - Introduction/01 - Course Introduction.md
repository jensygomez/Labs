# Course Introduction

#Linux/LFCS-Certification/Introduction

## 📌 Objetivo del curso
Preparar para la certificación LFCS (Linux Foundation Certified System Administrator).

## 🧠 Enfoque
- Aprendizaje práctico (hands-on)
- Uso real de comandos Linux
- Troubleshooting y administración

## 🛠️ Qué se espera del estudiante
- Practicar en terminal
- Repetir comandos
- Entender, no memorizar

## 🎯 Resultado esperado
Capacidad de administrar sistemas Linux en entornos reales.
