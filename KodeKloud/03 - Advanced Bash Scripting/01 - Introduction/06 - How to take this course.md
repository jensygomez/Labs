## Cómo Aprovechar Este Curso

A lo largo del curso encontrarás scripts de ejemplo en diferentes lecciones, todos diseñados para que los ejecutes en tu sistema siempre que tengas Bash instalado. Los scripts ejecutables incluyen un encabezado con el nombre del script y código con sintaxis resaltada. Este curso está optimizado para Bash versión 5.2 y utiliza principalmente las versiones GNU de utilidades de línea de comandos como sed, find y grep. Sin embargo, la mayoría de los scripts funcionarán correctamente en macOS o en puertos de Bash para Windows como Git Bash o Cygwin, lo que significa que tienes amplia flexibilidad en tu entorno de trabajo.

Para obtener la mejor experiencia, se recomienda **escribir manualmente cada script y comando** que aparece en las lecciones en lugar de solo ver los videos. Aunque requiere más tiempo, el esfuerzo de escribir y ejecutar cada script para entender qué hace crea una experiencia de aprendizaje superior. Esta recomendación es especialmente importante dado que el curso incluye ejercicios de laboratorio que refuerzan estos conceptos. El curso enfatiza el uso de **Vim** como editor principal, y se recomienda dominar un editor de línea de comandos como Vim o nano, ya que serán tus únicas opciones en muchos escenarios reales en tu trabajo como sysadmin.

### Comandos Esenciales para Verificar Tu Entorno

```bash
# Verificar versión de Bash
bash --version

# Verificar ubicación de Bash
which bash

# Verificar versiones de herramientas GNU
sed --version
grep --version
find --version
```
