## Descripción General

Instalación paso a paso de Docker en Ubuntu siguiendo la documentación oficial de Docker.

---

## Pasos de Instalación

### 1. Verificar la Versión del Sistema Operativo

- Comprobar la versión de Ubuntu instalada
- Asegurar compatibilidad con Docker

### 2. Remover Paquetes Innecesarios

- Eliminar paquetes previos o conflictivos de Docker
- Limpiar el sistema antes de la instalación

### 3. Agregar la Clave GPG Oficial de Docker

- Descargar e importar la clave GPG oficial
- Verificar la autenticidad de los paquetes

### 4. Agregar el Repositorio Oficial

- Configurar el repositorio oficial de Docker
- Garantizar obtener versiones actualizadas

### 5. Actualizar el Índice de Paquetes

- Ejecutar actualizaciones necesarias

### 6. Verificar la Instalación

- Confirmar que Docker se instaló correctamente
- Validar que todo está en orden

### 7. Verificar Versión Instalada

- Comprobar la versión exacta de Docker
- Confirmar que está lista para usar

---

## 🔑 Puntos Clave

- ✅ Usar siempre la **documentación oficial** de Docker
- ✅ Seguir el **flujo de verificación** en cada paso
- ✅ Usar **clave GPG oficial** para seguridad
- ✅ Validar el estado de la instalación antes de continuar
