# 🛠️ SKILL: Validação de Virtualização KVM no AlmaLinux 9 (Pré-Incus)

**Objetivo:** Preparar um servidor AlmaLinux 9 recém-instalado, validar o suporte a hardware KVM e levantar uma VM de teste em menos de 5 minutos usando imagens Cloud (evitando instalação via ISO demorada).

### 📋 Fase 1: Validação de Hardware (Pré-requisito)
Verificar se a CPU suporta virtualização e se o dispositivo KVM está presente.
```bash
# Verificar suporte de virtualização na CPU (deve retornar 'vmx' para Intel ou 'svm' para AMD)
grep -E -o 'vmx|svm' /proc/cpuinfo | sort -u

# Verificar se o dispositivo KVM existe e tem permissões corretas
ls -l /dev/kvm
```
*✅ Critério de sucesso: Saída mostra `vmx` ou `svm` e o arquivo `/dev/kvm` existe com permissão `crw-rw-rw-`.*

---

### 📦 Fase 2: Instalação Limpa de Pacotes
Instalar o grupo completo de virtualização e ferramentas de linha de comando em um único comando, evitando dependências quebradas.
```bash
# Atualizar o sistema (opcional, mas recomendado)
dnf update -y

# Instalar o grupo de virtualização e ferramentas essenciais
dnf groupinstall "Virtualization Host" -y
dnf install virt-install libguestfs-tools -y
```

---

### ⚙️ Fase 3: Configuração de Serviços e Permissões
Habilitar o daemon do libvirt e garantir que o usuário atual possa gerenciá-lo sem `sudo` constante.
```bash
# Habilitar e iniciar o serviço libvirtd
systemctl enable --now libvirtd

# Adicionar o usuário atual ao grupo libvirt (requer logout/login para surtir efeito)
usermod -aG libvirt $USER

# Validar a configuração do host (deve mostrar vários "OK" verdes)
virt-host-validate
```

---

### 💾 Fase 4: Configuração do Pool de Armazenamento e Rede
Garantir que o diretório padrão de imagens e a rede NAT estejam ativos.
```bash
# Criar e ativar o pool de armazenamento padrão
mkdir -p /var/lib/libvirt/images
virsh pool-define-as default dir --target /var/lib/libvirt/images
virsh pool-start default
virsh pool-autostart default

# Garantir que a rede padrão (virbr0) esteja ativa
virsh net-start default
virsh net-autostart default
```

---

### 🚀 Fase 5: Teste Rápido de VM (Método Cloud Image)
Usar uma imagem pré-instalada para levantar uma VM em segundos, provando que o QEMU/KVM está funcionando.
```bash
cd /var/lib/libvirt/images/

# 1. Baixar a imagem Cloud oficial do AlmaLinux 9 (qcow2)
wget https://repo.almalinux.org/almalinux/9/cloud/x86_64/images/AlmaLinux-9-GenericCloud-latest.x86_64.qcow2

# 2. Criar uma cópia para a VM de teste (nunca usar o original diretamente)
cp AlmaLinux-9-GenericCloud-latest.x86_64.qcow2 alma9-test.qcow2

# 3. Criar e iniciar a VM (2 vCPUs, 2GB RAM, conectada à rede default)
virt-install \
  --name alma9-test \
  --ram 2048 \
  --vcpus 2 \
  --disk path=/var/lib/libvirt/images/alma9-test.qcow2 \
  --os-variant almalinux9 \
  --network network=default \
  --import \
  --noautoconsole

# 4. Verificar se a VM está rodando
virsh list --all
```
*✅ Critério de sucesso: O comando `virsh list --all` mostra `alma9-test` com estado `executando` (running).*

---

### 🧹 Fase 6: Limpeza (Opcional)
Se o teste foi bem-sucedido e você quer limpar o ambiente antes de instalar o Incus:
```bash
# Desligar e remover a VM de teste
virsh destroy alma9-test
virsh undefine alma9-test

# Remover os arquivos de disco do teste
rm -f /var/lib/libvirt/images/alma9-test.qcow2
rm -f /var/lib/libvirt/images/AlmaLinux-9-GenericCloud-latest.x86_64.qcow2
```
