🐧 Guía: Linux Network Namespaces

Los network namespaces permiten aislar completamente la configuración de red de procesos, similar a contenedores. Cada namespace tiene su propia tabla de rutas, interfaces de red y reglas de firewall.

Comandos básicos:

• Crear namespace: ip netns add nombre
• Listar namespaces: ip netns list
• Ejecutar comando: ip netns exec nombre comando

🌉 Configuración de Linux Bridges

Los bridges permiten conectar múltiples interfaces de red como si fueran un switch virtual. Fundamentales para topologías de red complejas.

Crear y configurar:

• Crear bridge: ip link add br0 type bridge
• Activar: ip link set br0 up
• Añadir puerto: ip link set eth0 master br0

🔒 IPTables: Microsegmentación

Implementación de políticas zero-trust usando iptables para controlar el tráfico entre segmentos de red basándose en origen, destino y puerto.

Ejemplo de regla:
iptables -A INPUT -s 10.0.2.10 -p tcp --dport 80 -j ACCEPT
