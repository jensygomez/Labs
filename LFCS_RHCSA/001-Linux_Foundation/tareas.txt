📋 TRAIL: Linux Foundation Mastery (75 ejercicios)
🟢 NIVEL 1: El Explorador (Navegación y Archivos) [10 ejercicios]
Objetivo: Dominar la navegación, manipulación de archivos y redirecciones.
Navega hasta /var/log y lista todos los archivos ordenados por fecha de modificación (más recientes primero).
Crea la estructura de directorios /opt/practice/{docs,scripts,backups} con un solo comando.
Crea un archivo vacío llamado test.txt en tu home. Añádele 3 líneas de texto usando redirección >>.
Copia recursivamente /etc/skel a /tmp/skel-backup preservando permisos.
Mueve todos los archivos .tmp de /tmp a /tmp/old-files (crea el directorio si no existe).
Elimina recursivamente un directorio con contenido usando un solo comando.
Crea un enlace simbólico de /etc/hostname en tu home llamado my-hostname-link.
Crea un enlace duro de /etc/hostname en tu home llamado my-hostname-hard. Verifica con ls -i que comparten el mismo inodo.
Redirige la salida de ls /nonexistent a /dev/null para suprimir errores, y la salida estándar a ~/list.txt.
Encadena comandos: lista archivos de /etc, filtra los que contienen "host", y guarda el resultado en ~/hosts-files.txt.
🟡 NIVEL 2: El Buscador (Búsqueda y Procesamiento de Texto) [10 ejercicios]
Objetivo: Dominar find, grep, awk, sed, sort, cut, wc.
Encuentra todos los archivos .conf en /etc modificados en los últimos 7 días.
Busca archivos mayores a 10MB en todo el sistema y lista sus rutas.
Encuentra archivos que pertenezcan al usuario root y tengan permisos SUID.
Usa grep para buscar todas las líneas que contengan "error" (case-insensitive) en /var/log/messages.
Usa grep -E con expresiones regulares para extraer todas las direcciones IPv4 de /var/log/secure.
Usa awk para imprimir solo el nombre de usuario (columna 1) y el shell (columna 7) de /etc/passwd.
Usa sed para reemplazar todas las ocurrencias de "root" por "admin" en una copia de /etc/passwd.
Ordena /etc/passwd por UID (columna 3) numéricamente.
Cuenta cuántos usuarios tienen /bin/bash como shell usando grep y wc.
Combina find, xargs y grep para buscar la palabra "password" en todos los archivos .conf de /etc.
🟠 NIVEL 3: El Arquitecto (Usuarios y Grupos) [12 ejercicios]
Objetivo: Dominar la gestión de usuarios, grupos, contraseñas y envejecimiento.
Crea un grupo llamado developers con GID 2000.
Crea un usuario alice con home en /home/alice, shell /bin/bash, y miembro del grupo developers.
Crea un usuario bob con UID personalizado 1500 y sin directorio home.
Fuerza a alice a cambiar su contraseña en el próximo login.
Configura envejecimiento de contraseña para bob: cambio cada 90 días, aviso 7 días antes, inactividad 5 días.
Bloquea la cuenta de bob sin eliminarla. Verifica el estado en /etc/shadow.
Desbloquea la cuenta de bob y verifica.
Cambia el shell de bob a /sbin/nologin y verifica que no pueda iniciar sesión.
Añade a alice como miembro secundario de los grupos wheel y developers con un solo comando.
Elimina al usuario bob pero conserva su directorio home (si lo tiene).
Edita /etc/sudoers con visudo para permitir que el grupo developers ejecute /bin/systemctl restart httpd sin contraseña.
Crea un usuario serviceaccount con shell /sbin/nologin, sin home, y sin contraseña (cuenta de sistema).
🔴 NIVEL 4: El Guardián (Permisos y ACLs) [12 ejercicios]
Objetivo: Dominar permisos UGO, especiales, ACLs y atributos extendidos.
Crea un archivo con permisos 644 usando notación numérica y simbólica.
Crea un directorio con permisos 755. Cambia a 700 usando notación simbólica (u=rwx,go=).
Aplica el bit SUID a un script bash. Ejecútalo como usuario normal y observa que corre con permisos del dueño.
Aplica el bit SGID a un directorio /shared/team. Crea archivos dentro y verifica que heredan el grupo del directorio.
Aplica el Sticky Bit a /tmp/test-sticky. Intenta borrar un archivo de otro usuario desde una cuenta diferente.
Usa setfacl para dar al usuario alice permisos rwx sobre un archivo del que solo root es dueño.
Usa getfacl para ver las ACLs del archivo anterior. Elimina la ACL de alice.
Aplica ACLs recursivas a un directorio: grupo developers con r-x, usuario alice con rwx.
Usa chattr +i en un archivo crítico. Intenta modificarlo, borrarlo, renombrarlo. Luego quita el atributo.
Usa chattr +a en un archivo de log. Intenta sobrescribirlo, luego añade contenido con >>.
Configura umask 027 para un usuario específico de forma persistente en su .bashrc.
Encuentra todos los archivos en /opt con permisos 777 y cámbialos a 755.
🟣 NIVEL 5: El Ingeniero de Redes (Networking Básico) [10 ejercicios]
Objetivo: Dominar configuración de red, DNS, firewalld y SSH.
Usa nmcli para mostrar todas las conexiones activas y sus detalles.
Configura una IP estática 10.10.10.95/24 con gateway 10.10.10.1 y DNS 8.8.8.8 usando nmcli.
Crea una segunda conexión de red llamada "backup" con IP 10.10.10.96/24. Actívala y desactívala.
Cambia el hostname del sistema a lfcs-practice.local de forma persistente usando hostnamectl.
Edita /etc/hosts para que lfcs-practice.local resuelva a 127.0.1.1.
Usa firewall-cmd para agregar el servicio http a la zona public de forma permanente. Recarga y verifica.
Crea una Rich Rule en firewalld para bloquear todo el tráfico desde la IP 192.168.1.100.
Configura port forwarding en firewalld: puerto 8080 → puerto 80.
Genera un par de claves SSH ED25519 sin passphrase. Configura acceso sin contraseña al localhost.
Edita /etc/ssh/sshd_config para deshabilitar login por contraseña de root. Reinicia sshd y verifica.
🔵 NIVEL 6: El Automatizador (Systemd y Servicios) [8 ejercicios]
Objetivo: Dominar systemd, servicios, timers y programación de tareas.
Lista todos los servicios activos, fallidos y en espera usando systemctl.
Crea un servicio systemd personalizado /etc/systemd/system/myapp.service que ejecute un script simple.
Habilita el servicio para que inicie al boot. Inícialo, deténlo, reinícialo y verifica su estado.
Crea un systemd timer myapp.timer que dispare el servicio cada 5 minutos. Verifica con systemctl list-timers.
Programa un cron job que se ejecute todos los días a las 3:00 AM: echo "Backup done" >> /var/log/backup.log.
Programa un cron job que se ejecute cada 15 minutos los días hábiles (lun-vie).
Usa at para programar una tarea única que se ejecute en 10 minutos.
Analiza los logs de tu servicio personalizado con journalctl -u myapp.service --since "1 hour ago".
🟤 NIVEL 7: El Programador (Scripting Bash) [8 ejercicios]
Objetivo: Dominar scripting bash, condiciones, loops y funciones.
Crea un script que acepte un argumento (nombre de archivo) y muestre si existe, es un directorio, o no existe.
Crea un script que use un bucle for para procesar todos los archivos .txt en un directorio y contar sus líneas.
Crea un script que lea un archivo línea por línea y cuente cuántas líneas tienen más de 80 caracteres.
Crea un script que use if/else para verificar si un servicio está corriendo. Si no, intenta iniciarlo.
Crea un script que acepte múltiples argumentos y los procese uno por uno usando $@.
Crea un script que use trap para limpiar archivos temporales si se interrumpe con Ctrl+C.
Crea una función en .bashrc llamada mkcd que cree un directorio y entre en él con un solo comando.
Crea un script que use la salida de date como parte del nombre de un archivo de backup.
⚫ NIVEL 8: El Maestro de SELinux (Seguridad Avanzada) [5 ejercicios]
Objetivo: Dominar SELinux: modos, contextos, booleanos y políticas.
Verifica el modo actual de SELinux. Cámbialo a Enforcing de forma persistente en /etc/selinux/config.
Crea un archivo en /tmp y observa su contexto con ls -Z. Muévelo a /var/www/html y observa que el contexto NO cambia. Ahora cópialo y observa que SÍ cambia.
Usa restorecon -v para corregir el contexto de un archivo movido incorrectamente.
Habilita el booleano httpd_can_network_connect de forma persistente con setsebool -P.
Escenario final: Cambia el puerto de SSH a 2222. Usa semanage port para agregar el puerto 2222 al contexto ssh_port_t. Reinicia sshd y verifica que SELinux no lo bloquee.
